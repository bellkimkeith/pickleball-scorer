# Sound Assets

This folder should contain MP3 sound files (max 5 seconds each) for the soundboard feature.

## File Naming Convention

Name your files using the sound ID from the SoundManager:
- `airhorn.mp3`
- `cheer.mp3`
- `whistle.mp3`
- `meme1.mp3`
- `meme2.mp3`
- `meme3.mp3`
- `crowd.mp3`
- `applause.mp3`
- `boom.mp3`
- `bell.mp3`
- `horn.mp3`
- `buzzer.mp3`
- `laugh1.mp3`
- `laugh2.mp3`
- `wow.mp3`
- `noice.mp3`
- `yeet.mp3`
- `fail.mp3`
- `trombone.mp3`
- `rimshot.mp3`
- `sad.mp3`
- `village.mp3`
- `taco.mp3`
- `viking.mp3`

## Free Sounds (6)
These are included in the free tier:
- airhorn, cheer, whistle, meme1, meme2, meme3

## Pro Sounds (24 additional)
These require Pro subscription:
- crowd, applause, boom, bell, horn, buzzer, laugh1, laugh2, wow, noice, yeet, fail, trombone, rimshot, sad, village, taco, viking

## Requirements
- Format: MP3
- Duration: Max 5 seconds
- File size: Keep small for fast loading
