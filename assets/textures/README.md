# Textures

**court-grit.png** — 64×64 tileable speckle, generated (not photographed or
downloaded) by a deterministic script: seeded noise where ~6% of pixels carry a
faint light grain and ~6% a faint dark grain, at 4–9% alpha. It stands in for the
sand aggregate rolled into acrylic court paint, which is what keeps a real court
from reading as flat colour. Repeated behind the app's green ground.

Regenerate with the snippet in git history (uses `sharp`, already a dev
dependency). No third-party asset, no licence obligation.
