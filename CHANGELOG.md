# Changelog

All notable changes to this project will be documented in this file.

## [1.2.0] - Unreleased

### New Features
- **Open Play** - Run a whole session on one phone: everyone plays the same number of games whether they win or lose, partners rotate unless you lock a pair, late arrivals join fairly, and players can sit out and come back
- **Court & Paddle design** - Every screen redrawn: real top-down courts, players as paddles, the queue as a paddle rack
- **Session summary** - Games per player, frequent partners, and saved groups
- **Custom sounds** - Add your own short clips to the soundboard

### Pricing
- **Free, with every feature included** - Small banner ads appear on the home, stats and settings screens and in the session summary, never while you score
- **Remove ads** - Monthly, or once for life; restorable on a new phone and remembered offline
- Ad consent for the EEA, UK and Switzerland, with a way to change it in Settings

### Other
- Privacy policy rewritten for ads and purchases

## [1.1.0] - 2026-03-19

### New Features
- **Team/Player Color Indicator** - Visual colors to distinguish teams
- **Rally or Sideout Scoring** - Choose between rally scoring (any point) or sideout (only serving team scores)
- **Doubles Player Names on Win** - Winning players shown in doubles game win modal

### Improvements
- Dark mode enhancements and bug fixes
- Theme system refactored for better performance
- Updated scoring logic with improved side-switching
- Color palette improvements

### Bug Fixes
- Fixed undo functionality
- Fixed theme provider errors

### Other
- Privacy policy updated
